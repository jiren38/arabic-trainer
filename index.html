Come vengono scritte le pronunce

Convenzione semplificata: ث = th, ذ = dh, خ = kh, غ = gh, ش = sh, ج = j, ع = ' (apostrofo). Le enfatiche si scrivono come le simili: ص = s, ض = d, ط = t, ظ = z. ق = q (k accettata), ح e ه = h.

Senza harakāt si leggono le consonanti e i segni di vocale lunga: بت = bt. Le vocali brevi si scrivono con harakāt: fatḥa = a, kasra = i, ḍamma = u (بَت = bat, بِت = bit, بُت = but). Nelle parole, l’alif (ا) dopo una fatḥa allunga il suono in ā (ـَا = ā); non è una vocale breve “a”. In queste sequenze inventate, l’app usa ā per rendere udibile l’alif iniziale come vocale lunga. Scrivi ā oppure aa per la lunga; la sola a breve non viene accettata.

Quando scrivi in arabo, le harakāt sono facoltative: se le ometti, il correttore verifica le lettere; se le inserisci, verifica anche le vocali.
